# Head Soccer (Unity project)

Unity **6000.3.20f1**, URP 2D. Open `Assets/Scenes/Menu.unity` and press Play.

See the repository [README](../README.md) for controls, the Android build and the list of course concepts, and [`Docs/GDD.md`](../Docs/GDD.md) for the design document.

## Editor menu

- **Head Soccer → Build Everything** regenerates `GameConfig`, `CharacterRoster`, the effect prefabs and both scenes from the art in `Assets/Art`. Safe to rerun; existing tuning assets are kept.
- **Head Soccer → Build Android APK** / **Build Windows (x64)** write to `Builds/`.
